# D355 — la CARTE du journal de DR5, en entier (R-3, versée AVANT tout code)

**Ce que DR5 liste** (`ZWADJ_CONTINUITE.md`, bloc DR1 à DR8, ligne « Journal », recopiée à l'identique dans la table d'ouverture, § E) : `audit_logs.actor_member_id` « sur toute action de personnel (connexions, échecs, verrouillage, déblocage, création, réinitialisation, désactivation, recherche d'annuaire, création et modification de fiche) » — **neuf** éléments, relevés dans l'ordre de la ligne.

**Comment la carte est relevée** (consigne, R-3 : « ce qui l'écrit aujourd'hui (fichier, test) ou « pas encore » avec le lot qui le doit ») : par RECHERCHE de chaque action dans `apps/api/src/staff/staff-store.prisma.ts` et `staff-session.service.ts` (le code qui l'écrit), puis dans les **77** fichiers de test (`apps/api/test/int/*.ts` et `apps/api/src/staff/*.spec.ts`) pour le **test englobant** de la première occurrence de chaque action (instrument : un script de relevé joué à l'ouverture, sa sortie lue ici ; les titres sont ceux des `it(…)`, tronqués). **Aucune ligne n'est écrite de mémoire.** Les numéros de ligne sont ceux de `cc653dd`, avant toute modification du lot.
